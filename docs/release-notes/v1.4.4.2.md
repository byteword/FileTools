# FileTools v1.4.4.2

This stable patch release cleans up the archive merge progress dialog decision
panel and bumps the default repository version metadata to `1.4.4.2`.

## Highlights

- Hid the archive merge decision button row while there are no pending merge
  decisions so the progress dialog no longer shows three empty disabled button
  slots.
- Archive merge decision buttons now size to their localized labels when a
  pending decision is shown.
- Bumped the stable release line to `1.4.4.2`.

## Support Scope

- No runtime support scope change. ZIP input and ZIP output remain the
  supported archive merge scope; 7Z input remains deferred under issue #8.

## Release Assets

- `FileTools-1.4.4.2-win-x64-setup.exe`: normal signed installer bootstrapper.
- `FileTools-1.4.4.2-win-x64.msi`: direct signed MSI package.
- `FileTools-1.4.4.2-win-x64-identity.msix`: signed sparse package identity for Windows 11 native context menus.
- `FileTools-1.4.4.2-msix-self-signed.cer`: public certificate used to sign the self-signed MSIX identity package.
- `checksums.txt`: SHA256 checksums for the release assets.
