# FileTools v1.5.0.0 — Unreleased

Development version on `codex/1.5.0.0`, prepared for commit and push on 2026-09-19.
No release tag, GitHub Release or installation package is published by this change.

## Highlights

- Empty-folder cleanup: review empty branches, preserve selected roots by default,
  and move approved folders to the Recycle Bin. Check emptiness and linked paths
  before applying, keep failed candidates for retry, and never add newly discovered
  folders during execution.
- Batch filename editing: literal replacement, prefix/suffix removal and addition,
  name patterns, extension preservation, and numbering by natural name, input order,
  modification time or creation time. Review invalid names and collisions together.
- Execution preserves approved names, rechecks source identity/metadata, avoids
  overwriting existing destinations and updates successful planner targets.
- Both features are available through the app's Tasks menu and work plan, with
  Korean/English dialogs. See [usage and actual screenshots](../file-organization.md).

## Version and Scope

App, native ShellExt, installer, bundle, resource fallbacks and related documentation
are synchronized from `1.4.7.0` to `1.5.0.0` (minor increment).
Duplicate inspection improvements, file-list export and conditional file collection
remain planned phases 3–5. New dedicated Explorer commands are not included.
