# FileTools v1.4.5.0

This release improves folder merge review before execution, moves merge
destination naming onto a shared correction-aware proposal path, and bumps the
default repository version metadata to `1.4.5.0`.

## Highlights

- Merge destination names now use a shared proposal builder that can apply safe
  rename correction before common-stem and range analysis.
- Folder merge, archive merge, and folder wrapping all route generated names
  through the shared naming/correction foundation where applicable.
- The folder merge options dialog now uses a wider resizable layout with an
  editable destination name, readable destination path, consistent merge-mode
  choices, and a selected item list.
- The old lower explanatory message box in the folder merge dialog has been
  replaced with a direct list of the files/folders that will be merged.
- Folder contents-only mode is now visible consistently and can be selected
  whenever at least one selected item is a folder.
- Korean folder merge mode labels are aligned to `폴더 단위로 병합` and
  `폴더 내용만 이동`.
