# FileTools v1.4.5.1

Release date: 2026-06-20

## Highlights

- Fixed the folder merge options dialog footer so `확인` and `취소` keep a
  stable bottom-right layout under resize and DPI scaling.
- Fixed common destination name extraction for Korean volume ranges such as
  `01권 - 20권` plus `21권 - 38권`, producing the merged title/range instead
  of a repeated suffix like `권[총 38권][완결]`.
- Bumped default repository version metadata to `1.4.5.1`.
