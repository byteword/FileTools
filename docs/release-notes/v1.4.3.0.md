# FileTools v1.4.3.0 Beta

This prerelease exposes the remaining implemented context-menu entry points and
adds generated ZIP release-sample regression coverage before the 1.4 beta line
moves toward stable validation.

## Highlights

- Added Explorer/Windows 11 context-menu exposure for file comparison.
- Added a context-menu command for single-file-folder unwrap using the
  folder-file naming mode.
- Added generated ZIP release-sample regression coverage for UTF-8 filenames,
  legacy CP949 filenames, legacy Shift-JIS filenames, archive and entry
  comments, directory entries, external attributes, local/central extra fields,
  collision auto-numbering, and same-content duplicate skipping.

## Beta Scope

- File compare opens FileTools and preloads the file compare settings dialog
  with the selected paths.
- Prefix-name unwrap uses the same single-file-folder visibility and settings
  gate as the existing folder-name/file-name unwrap commands.
- ZIP input and ZIP output remain the supported archive merge scope; 7Z input
  remains deferred under issue #8.
- Very large ZIPs and ZIPs produced by external tools may still show
  producer-specific behavior beyond the generated regression corpus.

## Assets

- `FileTools-1.4.3.0-win-x64-setup.exe`: normal signed installer bootstrapper.
- `FileTools-1.4.3.0-win-x64.msi`: direct signed MSI package.
- `FileTools-1.4.3.0-win-x64-identity.msix`: signed sparse package identity for
  Windows 11 native context menus.
- `FileTools-1.4.3.0-msix-self-signed.cer`: public certificate used to sign the
  self-signed MSIX identity package.
- `checksums.txt`: SHA256 hashes for the release assets.
