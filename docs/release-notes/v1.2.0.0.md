# FileTools v1.2.0.0

## Highlights

- Added editable AutoRelocation file-kind classification, including custom kinds, representative names, extension rules, and Windows system extension lookup.
- Expanded rename-rule settings with candidate and parser profiles for common phrases, protected words, tag words, author prefixes, episode prefixes/units, and title noise words.
- Added folder operation name-template settings for wrap/unwrap naming and collision numbering.
- Added selected target folder merge for combining multiple selected files and folders into one generated destination folder.
- Hardened rename safety checks so empty, unsafe, duplicate, and colliding target names are blocked before apply.
- Split dialog UI layouts into designer partials to keep WinForms Designer support maintainable.

## Assets

- `FileTools-1.2.0.0-win-x64-setup.exe`: normal signed installer bootstrapper.
- `FileTools-1.2.0.0-win-x64.msi`: direct signed MSI package.
- `FileTools-1.2.0.0-win-x64-identity.msix`: signed sparse package identity for Windows 11 native context menus.
- `FileTools-1.2.0.0-msix-self-signed.cer`: public certificate used to sign the self-signed MSIX identity package.
- `checksums.txt`: SHA256 hashes for the release assets.

These assets are signed with the FileTools self-signed certificate. Windows does not trust this certificate by default.

Setup installs the Windows 11 native context menu support files only. FileTools settings can import the certificate into the current user's Trusted People store and register the sparse package identity when the user explicitly chooses that action.

Verify the SHA256 hashes and GitHub artifact attestations before installing.
