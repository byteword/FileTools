# FileTools v1.5.0.1 — Unreleased

Development version on `codex/1.5.0.0`, prepared for a checkpoint commit on 2026-09-19.
No release tag, GitHub Release or installation package is published by this change.

## Highlights

- Existing file comparison now has a content-only preset and explicit comparison scope.
  Whole-file evidence is required for cleanup; keeper/identity/content checks guard
  Recycle Bin execution. JSON export is schema 3. See [usage](../file-compare.md).
- Latest validation: managed Release build and 279 tests, including 39 new checks;
  real dialog/planner handoff and temporary-file recycle/restore passed.

- CSV/TXT file-list export with selected columns, sorting, custom file kinds,
  CSV formula protection and temporary-file commit on successful completion.
- Conditional target collection by kind, extension, name, created/modified local
  dates and size, with exclusions, hidden/system options and checked results.
  Existing targets and work plans are retained. See [file catalog](../file-catalog.md).
- Includes master hotfix `35187dd` from 1.4.7.1: Explorer subcommands remain usable
  when only fast state callbacks arrive. Detailed deduplication still requires a
  completed analysis; conservative extra commands may remain visible otherwise.
- Empty-folder cleanup: review empty branches, preserve selected roots by default,
  and move approved folders to the Recycle Bin. Check emptiness and linked paths
  before applying, keep failed candidates for retry, and never add newly discovered
  folders during execution.
- Batch filename editing: literal replacement, prefix/suffix removal and addition,
  name patterns, extension preservation, and numbering by natural name, input order,
  modification time or creation time. Review invalid names and collisions together.
- Execution preserves approved names, rechecks source identity/metadata, avoids
  overwriting existing destinations and updates successful planner targets.
- Both features are available through the app's Tasks menu and work plan, with
  Korean/English dialogs. See [usage and actual screenshots](../file-organization.md).

## Version and Scope

App, native ShellExt, installer, bundle, resource fallbacks and related documentation
are synchronized from `1.5.0.0` to `1.5.0.1` (build increment).
File-list export and conditional collection are implemented as phases 4 and 5.
Phase 3 existing-comparison improvements are implemented; further enhancements remain deferred. New dedicated Explorer commands are not included.
