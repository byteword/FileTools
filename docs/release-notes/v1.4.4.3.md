# FileTools v1.4.4.3

This release standardizes the final destination-name review flow for merge and
folder wrapping operations, improves automatic name generation, and bumps the
default repository version metadata to `1.4.4.3`.

## Highlights

- Folder merge, folder wrapping, and archive merge now share merge-name
  generation so compact ranges such as `01~06` can be suggested when selected
  names form a continuous range.
- Disjoint ranges are preserved in generated names, for example
  `01~03, 05~08`.
- Common name elements can be detected across the whole stem instead of only at
  the start, allowing shared middle tokens and text ranges to survive in the
  final editable name.
- Archive merge and folder merge/wrapping flows now show the final destination
  name before execution, then run immediately after confirmation.
- Korean folder wrapping/unwrapping menu labels are aligned to `폴더 씌우기` and
  `폴더 벗기기` across the app, ShellExt, installer fallback menus, and docs.
