# FileTools v1.4.5.2

Release date: 2026-06-22

## Highlights

- Native Explorer context-menu unwrap commands now appear for mixed
  multi-folder selections when at least one selected folder matches the command
  condition.
- Context-menu unwrap execution now filters queued multi-folder selections so
  only folders matching the selected unwrap command are processed.
- Bumped default repository version metadata to `1.4.5.2`.
