# FileTools v1.4.1.0 Beta

This prerelease replaces the previous 1.4.0.0 beta and is the current 1.4-line
validation build. It includes the planner refresh, folder-merge option workflow,
local rename-learning foundation, release build hardening, and late fixes found
during beta validation.

## Highlights

- Reworked the standalone planner into a top target/task-log area and a bottom
  work-plan review area.
- Added all-plan, selected-target, and warning filters backed by the
  UI-independent `WorkPlanDisplayBuilder` projection.
- Improved grouped work-plan display for shared and multi-input operations,
  including archive-merge and duplicate-delete input rows.
- Added connector-style grouped input rendering and regression coverage for the
  grouped row mapping helpers.
- Added in-app right-click context menus for the target and plan grids.
- Added a folder-merge options flow with target folder name editing and
  selectable merge modes, including "merge folder contents only" for multiple
  folders.
- Fixed folder-merge options dialog layout so localized Korean text no longer
  overlaps the confirmation button row.
- Added local rename pattern-learning foundation: deterministic pattern
  discovery, render candidates, bounded JSONL feedback storage, statistical
  ranking, and settings for enabling the future feature.
- Restored short Yaminjeongeum/obfuscated Hangul candidates such as
  `ㅇr -> 아` and `ㅎH -> 해`.
- Work-plan completion now removes applied steps, refreshes moved/renamed target
  paths, removes deleted targets, supports multi-step removal, and limits
  selection-triggered plan refreshes to the selected-target view.
- Hardened the release workflow with .NET SDK pinning, artifact attestation
  permissions, existing-release note refresh, and reproducible version checks.

## Beta Scope

- The standalone planner layout and grouped work-plan rendering are available
  for beta validation. Manual validation at small, default, and wide window
  sizes should continue.
- Folder merge options are available from both in-app flows and context launch
  paths, with preview/confirmation before moving files.
- Rename personalization remains foundational and review-first. Automatic
  rename application, review-dialog feedback recording, neural shadow
  validation, and UI candidate-order integration remain future work.
- ZIP archive merge and file comparison remain beta features from the previous
  release line. 7Z input, file-compare JSON import/reload, and Explorer file
  compare exposure remain deferred.

## Assets

- `FileTools-1.4.1.0-win-x64-setup.exe`: normal signed installer bootstrapper.
- `FileTools-1.4.1.0-win-x64.msi`: direct signed MSI package.
- `FileTools-1.4.1.0-win-x64-identity.msix`: signed sparse package identity for
  Windows 11 native context menus.
- `FileTools-1.4.1.0-msix-self-signed.cer`: public certificate used to sign the
  self-signed MSIX identity package.
- `checksums.txt`: SHA256 hashes for the release assets.
