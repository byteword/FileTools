# FileTools v1.4.6.4

Release status: Pending local installation verification

## Highlights

- Fixed folder move-up so direct child folders move upward with files, including
  same-name nested folder layouts such as `A\A\B`.
- Added an `자동교정` button beside `고급` in the simple rename confirmation.
  It uses the same automatic-correction fallback order as the advanced editor.
- Bumped default repository version metadata to `1.4.6.4`.

## Verification

  passed 144/144 on 2026-07-20.
- `build_msi.ps1 -Configuration Release` completed on 2026-07-20. Local
  installer verification is pending user review before any GitHub release.
