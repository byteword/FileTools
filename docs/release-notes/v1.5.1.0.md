# FileTools v1.5.1.0 — Test Build

This patch fixes the Explorer submenu visibility regression from 1.4.7.1.
The catalog, collection and comparison changes from the 1.5.0.1 checkpoint are included.

## Behavior

- Normal local folders are classified on the first submenu state request, even if
  Explorer never supplies a later slow callback. Equivalent unwrap operations are hidden.
- The same selected paths reuse their result across new selection COM objects.
  Opening a new menu creates a fresh snapshot so changed folder contents are reconsidered.
- Filesystem analysis runs on a background worker. Each selection has one 50 ms
  wait budget, shared by all sibling commands. Timeouts/errors retain usable conservative
  states; at most two analyses may be outstanding. No unbounded wait or worker queue is used.
- UNC/network, reparse and offline/recall folders remain conservative. The Shell
  provider's own path/attribute calls are outside the filesystem-worker wait budget.
- Workers own their input and keep the DLL loaded until their callback has returned.

## Version and delivery

All app, ShellExt, installer/bundle and resource version sources use **1.5.1.0**:
patch +1 from 1.5.0.1, build reset to 0. Branch remains `codex/1.5.0.0`.
A local signed test setup/MSI is produced. No public release/tag or automatic installation.
