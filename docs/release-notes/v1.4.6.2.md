# FileTools v1.4.6.2

Release date: 2026-06-24

## Highlights

- Fixed the simple rename review dialog so filename correction can open for
  single and multi-file selections without a `SelectedIndex` out-of-range error.
- Bumped default repository version metadata to `1.4.6.2`.
- Updated `build_msi.ps1` so it reads `FileToolsVersion` from project files when
  `-Version` is omitted and fails early if version metadata is out of sync.

## Verification

- `dotnet test tests\FileTools.Tests\FileTools.Tests.csproj` passed 140/140 on
  2026-06-24.
- `MSBuild.exe FileTools.sln /p:Configuration=Debug /p:Platform=x64 /m` passed
  with 0 warnings and 0 errors on 2026-06-24 using VS 18 MSBuild.

## Packaging Notes

- Build or dry-run `build_msi.ps1` before tagging to confirm installer version
  propagation. Passing `-Version v1.4.6.2` is still supported, but it must match
  the project `FileToolsVersion` metadata.
