# FileTools v1.4.6.0

Release date: 2026-06-23

## Highlights

- Added a simple file rename confirmation dialog with original name, new name,
  Advanced, OK, and Cancel controls.
- Added a single-name advanced editor with original-name restore, automatic
  correction, and recommended text chips.
- Connected the advanced editor to file rename, folder wrap, folder merge, and
  ZIP archive merge output name confirmation flows.
- Bumped default repository version metadata to `1.4.6.0`.
