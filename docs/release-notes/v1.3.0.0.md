# FileTools v1.3.0.0 Beta

This is a beta release. It is intended for early validation before the same
feature line is promoted to stable after additional real-world ZIP merge, file
comparison, and rename-correction plugin stabilization.

## Highlights

- Added ZIP input to ZIP output archive merge with collision handling, filename
  encoding selection, metadata preservation, and detailed internal entry
  preview.
- Added the first file-comparison workflow, including the compare dialog,
  expanded options, modeless progress, JSON export, and duplicate-delete step
  handoff.
- Added the first rename-correction plugin boundary with language selection,
  review-only candidate generation, and a SymSpell sample provider that uses
  user-supplied dictionary or corpus data.
- Aligned release versioning so GitHub release tags drive the app binary,
  generated app manifest, MSI, Burn bundle, and sparse MSIX identity versions.

## Beta Scope

- ZIP input and ZIP output are supported for archive merge.
- File comparison is available as an active-development beta workflow. JSON
  result import/reload and Explorer menu exposure remain deferred.
- Rename correction plugins are limited to local review-only candidates.
  Internet dictionary and local LLM providers remain deferred.
- 7Z input is not supported in this beta. Track 7Z input archive merge in
  GitHub issue #8.
- Archive-first common-filename merge is included through archive merge output
  naming and entry preview. General file-content merge remains deferred under
  GitHub issue #9.

## Assets

- `FileTools-1.3.0.0-win-x64-setup.exe`: normal signed installer bootstrapper.
- `FileTools-1.3.0.0-win-x64.msi`: direct signed MSI package.
- `FileTools-1.3.0.0-win-x64-identity.msix`: signed sparse package identity for
  Windows 11 native context menus.
- `FileTools-1.3.0.0-msix-self-signed.cer`: public certificate used to sign the
  self-signed MSIX identity package.
- `checksums.txt`: SHA256 hashes for the release assets.
