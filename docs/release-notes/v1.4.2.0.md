# FileTools v1.4.2.0 Beta

This prerelease keeps the 1.4 beta line focused on standalone planner
validation while adding a small program information surface and a rename
candidate fix found during Korean filename correction review.

## Highlights

- Added Settings > Program info so users can check the running app version and
  bundled MIT license text from inside FileTools.
- Expanded obfuscated Hangul rename candidates so mixed fragments like
  `혀ㄴ주ㅇ구l호rㄴ로ㄱ` are offered as `현중귀환록`.

## Beta Scope

- Program information is shown from the WinForms app and reads the version from
  assembly metadata.
- The MIT license text is embedded into the app assembly so it remains available
  after installation.
- The obfuscated Hangul candidate rule composes prebuilt Hangul syllables with
  adjacent jamo or Latin-shaped vowel fragments before scoring candidates.
- The standalone planner, ZIP archive merge, file comparison, and rename
  personalization features remain in beta validation.

## Assets

- `FileTools-1.4.2.0-win-x64-setup.exe`: normal signed installer bootstrapper.
- `FileTools-1.4.2.0-win-x64.msi`: direct signed MSI package.
- `FileTools-1.4.2.0-win-x64-identity.msix`: signed sparse package identity for
  Windows 11 native context menus.
- `FileTools-1.4.2.0-msix-self-signed.cer`: public certificate used to sign the
  self-signed MSIX identity package.
- `checksums.txt`: SHA256 hashes for the release assets.
