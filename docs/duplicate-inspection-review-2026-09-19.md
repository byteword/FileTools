# 3번 기능 재검토: 기존 파일 비교 보완

검토일: 2026-09-19. 상태: **사용자가 승인한 축소 범위 구현·검증 완료**. [사용 방법과 검증](file-compare.md)을 참고한다.
사용자 피드백에 따라 중복 관리 전문 기능으로 확장했던 이전 제안을 대체한다.

## 목적

파일 정리 중 같은 파일인지 확인하고, 필요하면 기존 작업 계획으로 정리할 수 있게 한다.
이번 범위는 기존 비교 기능의 정확성·편의·실행 검증을 보완하는 세 가지다.

## 제안하는 세 가지

1. **내용만 비교하기를 쉽게 한다.**
   기존 비교 기능에서 ‘내용만 비교’ 설정을 쉽게 적용한다.
   이 설정은 이름·작성일·수정일을 판정에서 빼고 파일 전체 내용을 확인한다.
   예: `사진.jpg`와 `사진 - 복사본.jpg`가 같은 파일인지 바로 확인한다.
   기존 이름/날짜/부분 구간/ZIP 엔트리 상세 비교는 유지한다.

2. **결과의 의미를 명확히 한다.**
   ‘전체 내용 같음’, ‘선택 구간 같음’, ‘압축 내부 비교’, ‘내용 다름’,
   ‘확인 실패’를 비교 범위와 함께 구분한다.
   이름·날짜만 확인한 결과에도 내용 검증 여부를 명시한다.
   부분 구간이나 일부 ZIP 항목의 일치를 전체 파일이 같다는 뜻으로 취급하지 않는다.
   기존 결과에서 전체 내용이 같은 파일을 확인하고 남길 파일을 선택하는 흐름을 다듬는다.

3. **기존 휴지통 정리를 안전하게 마무리한다.**
   전체 내용이 확인된 파일만 기존 정리 단계로 넘긴다.
   같은 파일 중 최소 하나를 남기고, 실행 직전에 보존본과 후보를 다시 확인한다.
   파일 변경·교체·보존본 소실·다른 작업과의 충돌은 해당 정리를 보류한다.
   휴지통을 사용할 수 없을 때 영구삭제로 전환하지 않는다.

## 내부 보완

- 현재 기본 설정은 이름/수정일이 다르면 내용 비교 전에 종료할 수 있으므로 내용 비교 설정을 분명히 한다.
- 현재 그룹 판정은 상태와 기준 이름에 의존한다. 전체 파일 비교 여부를 명시적인 정보로 전달한다.
- 작업 계획과 실행기까지 보존본과 파일 식별/검증 정보를 연결한다.
- 대량 비교의 모든 쌍 생성 문제는 남아 있다. 이번에는 불필요한 읽기·중복 계산을 줄일 수 있는 범위를 검토하되,
  별도 그룹 검색 엔진과 전용 검색 기능의 신설은 독립된 성능 과제로 남긴다.
  소규모 보완으로 대량 검색 문제가 해결됐다고 주장하지 않는다.
- 기존 JSON 내보내기에 검증 범위 정보가 필요하면 형식을 갱신한다.
  저장 결과 다시 열기는 기존 후속 과제로 유지하며 이번 완료 조건에 넣지 않는다.

## 이번 제안에서 제외

기준 폴더 모드, 별도 검색 조건, 전용 중복 관리 화면, 보존 추천 규칙 확대,
용량 중심 대시보드, 중복 전용 CSV 보고서, JSON 다시 열기, 상시 감시, 유사 이미지 검색.
필요한 대상 선별과 목록 저장은 이미 구현한 5번과 4번 기능을 사용한다.
이전 전용 관리 화면 확대안은 철회했다.
새로운 화면 배치는 이번 재검토에서 제안하지 않는다.

## 완료 기준

- 이름과 날짜가 다른 동일 파일을 내용 비교 설정으로 확인할 수 있다.
- 일부 구간/일부 ZIP 항목만 같은 파일은 전체 중복 정리 후보가 되지 않는다.
- 그룹의 모든 파일을 정리 대상으로 선택할 수 없다.
- 검색 뒤 파일 변경/교체, 보존본 삭제, 링크, 충돌 작업을 실행 직전에 검증한다.
- 정상 후보는 휴지통으로 이동하며 실패/취소 결과가 구분된다.
- 기존 상세 비교 설정과 결과 내보내기가 유지된다.

승인 후 위 세 가지를 구현했다. Release 전체 279개 테스트와 실제 휴지통 이동/복원을 확인했다. 추가 고도화는 후속 검토 후 결정한다.
